# Лабораторная работа: Микросервисы «Умный планировщик задач»

Данный проект демонстрирует интеграцию двух независимых микросервисов на базе **FastAPI** с использованием событийной модели взаимодействия через **Webhook**.

## Архитектура системы
1. **Task Service (порт 8001)** — отвечает за бизнес-логику создания задач. При успешном сохранении генерирует событие и асинхронно отправляет его на сервер уведомлений.
2. **Notification Service (порт 8002)** — слушает входящие вебхуки и симулирует отправку уведомлений пользователям.

## Развертывание и запуск

1. Установка всех необходимых зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

2. Запуск юнит-тестов для проверки работоспособности схемы:
   ```bash
   python -m pytest test_main.py
   ```

3. Локальный запуск микросервисов (выполнять в разных терминалах):
   ```bash
   # Терминал 1
   python notification_service.py

   # Терминал 2
   python task_service.py
   ```
